I am an independent developer based in Kyoto.

I am currently developing **[SpinningCube.run](https://spinningcube.run)**, a local-first repository verification tool focused on providing reproducible evidence.

My primary areas of interest include:

- Compilers and toolchains
- Program analysis
- Software verification
- Operating systems and kernels
- Debuggers and binary formats
- Concurrency and memory behavior
- Reproducible execution
- Systems programming

I started developing SpinningCube when I was around 16 years old. My approach involved reading research papers, compiler source code, and kernel documentation, then iteratively implementing the concepts until the ideas became working software.

I lost access to my GitHub account twice in the past, so the old commit history is no longer available, but I was working on similar projects back then as well.

I still handle everything—design, development, maintenance, and operations—on my own.

## SpinningCube.run

Connect a repository.

Press the button:

**Start verification**

That is essentially the entire UI.

...Though the implementation behind it is a bit more complex. :)

During standard verification, your source code remains within your local environment. No account registration is required for basic usage.
